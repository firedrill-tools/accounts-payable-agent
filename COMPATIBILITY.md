# Exercised runtime contract

Python 3.12; Google ADK **2.12.0**, Google GenAI **2.31.0**, HTTPX **0.28.1**, Pydantic **2.14.1**. Direct pins and uv.lock record the exercised environment. The normal path constructs Gemini with its public `client` field, an explicit Developer API client and its owned HTTPX async client. No default/global model, vendor-source patch, streaming, Vertex, enterprise or remote accounting connector is qualified. See [ADK Gemini models](https://adk.dev/agents/models/google-gemini/) and [LLM agents](https://adk.dev/agents/llm-agents/).

The original ADK runner accepted structured facts under STOP, MAX_TOKENS, SAFETY and absent finish and left sessions behind. Pre-normalization public HTTP hooks now require one STOP model text candidate, rejecting blocked/multiple/empty/tool/executable/media content. JSON extras, malformed fields and absent structured output fail. The runner uses one LLM call, one candidate, nonstreaming chat and 4096 output tokens. SDK retries are one total attempt, phase/connect limits 30/five seconds and overall service deadline at most 120 seconds. Request bytes are limited before dispatch; response evidence is capped after buffering at 1 MiB, not a wire/memory bound.

Original provider body/unknown fields, request/response/model IDs, finish, status, raw counters and error evidence are retained separately from SDK events and normalized fields. Missing/partial/invalid/zero usage remains distinct and provider totals are independent. No guessed cost. Recording faults latch before subsequent publication; raw observations are saved before accepting facts. A failure after SQL commit or final recording does not imply rollback: final state is reread and actual_invoice/facts_recorded_by_run report effects. A failed final persistence can leave the last file running; exception evidence retains the failure. No blind automatic publication retry.

Every extraction owns a fresh session/runner and normal SDK/HTTP clients. Cleanup deletes sessions and explicitly closes both SDK and injected HTTP clients: the SDK intentionally does not close a supplied HTTPX client. Startup, malformed completion, cancellation/deadline and actual CLI signals exercise these paths. Caller-injected BaseLlm models retain their clients and are labeled separately; their SDK events are not raw HTTP provider evidence. An unused transport on cached/preflight processing remains caller-owned. No detached write thread is started. SQLite waits are 100 ms and active/deadline/cancellation guards run inside the facts transaction before commit.

SQLite schema version 2 adds immutable source/fact hashes, extraction ownership/attempt history, named approval binding and PO-bound ledger evidence. Legacy rows/actions remain intact with legacy_unknown provenance; old approvals lacking a fingerprint require fresh review. Canonical NFKC/case/whitespace/dash identity rejects ambiguous vendors and duplicates across POs without rewriting original invoice strings. Approval binds current facts/source, directory revisions, PO revision and prior PO ledger. Posting transaction rechecks the exact binding, remaining balance and original vendor/currency. Exact post replay adds no second entry/action. One full-value invoice can consume a PO; partial billing is not implemented. Local actor names and fingerprints are not authentication or evidence of human attention.

A durable exclusive lease fences same-source extraction before a second model call. Source bytes/hash and token/run ownership are checked under facts commit. No age-based takeover. A manual stopped-owner command needs the exact token and explicit assertion; it cannot release a replacement owner. Existing facts return model-free, even without provider config. Such recovery is not a new quality trial. Cases use independent databases. New DBs/receipts use 0600 and new directories 0700; WAL/SHM inherit DB privacy. Existing parent modes are preserved.

Model input contains one source only, never vendor/PO history or manifest focus. The model quotes the amount and code uses exact Decimal integer ratios with USD/CAD/EUR/GBP=2, JPY=0, KWD=3; no float conversion, rounding, fractional minor units or unsafe integers. Only this subset is supported. The [official SIX list](https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml), published **2026-09-17**, was checked on 2026-10-15; SHA256 **33139b438657d1cee116ba737807ea71d19d6de4b90f799a09c56f0cc6a1b0ff**. Six factual exponent values are retained, not a full copied currency dataset. Facts require normalized source phrase boundaries; occurrence does not prove semantic entailment, total selection or extraction quality. Human source review remains required.

Twelve deterministic SHA-bound cases/four profiles include eight-vendor/twenty-PO/eighteen-source busy state, twelve prior human-import invoices, six ledger rows and fifteen human actions. Initializers validate bounded strict schema, identity, populations, relationships and confined paths, reserve private exclusive destinations and never invoke a model. Prior human history has explicit timestamps/origin without invented provider usage. Fresh locked wheel/sdist installs exercise installed console/module CLI, all cases, missing-key receipt, exact arithmetic and real approval/post/recovery outside checkout. Native HTTP tests use controlled transports and loopback child CLI, not live model judgment. macOS/Linux signals are tested; Windows signal behavior is unqualified.

Live Gemini judgments/billing, the new Firedrill release and persisted scenarios, publication and licensing remain external gates.
